# Conventions

* [AI workflow](ai-workflow.md) - Compound Engineering loop with human gates, skills, learning summaries.
* [Git](git.md) - Branches, Conventional Commits with `[gen]`, push policy, one task per session, optional worktrees.
* [Testing](testing.md) - Mandatory Vitest + Playwright/axe; testing camera features without a camera.
* [Frontend](frontend.md) - Angular 22, Transloco, Tailwind, mobile-first, pure-TS domain logic.
* [Accessibility](accessibility.md) - WCAG 2.2 AA for the caregiver UI and AAC rules for the communicating person.
* [Security and privacy](security.md) - Threat model, headers, untrusted boards, on-device privacy, supply chain.
